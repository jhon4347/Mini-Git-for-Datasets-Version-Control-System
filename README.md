# Mini-Git-for-Datasets-Version-Control-System
Engineered a high-performance C++ version control CLI for ML datasets. Replaces bloated CSV duplication with efficient in-memory deltas. Leverages dynamic programming (LCS) for row diffing, DAGs for commit branching, and Hash Maps for O(1) rollbacks. Built to solve real-world data pipeline bottlenecks using advanced system design and DSA.
